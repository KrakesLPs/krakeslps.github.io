The Unofficial Mid-Offs Tracker

About

This is a fun little tracker to see where all the Mid-Offs contestants have gone on their MCSR Journey post Mid-Offs. Following stats are being tracked:

  • Peak Elo
  • Current Elo
  • PB
  • Season Average
  • Number of Ranked Matches
  • Number of Casual Matches
  • Number of Private Room Matches
  • Mid-Offs Tourney Performance

My goals when making creating this website are the following:

  1. Making sure I know how good I have to be at the game to be ahead of all the Mid-Offs Players
  2. Seeing wether or not better Mid-Offs performance correlates with better Ranked performance
  3. Something else

All the data for this website is compiled from the MCSR Ranked Api
