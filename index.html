The Unofficial Mid-Offs Tracker

About

This is a fun little tracker to see where all the Mid-Offs contestants have gone on their MCSR Journey post Mid-Offs.

My goals when making this website are the following:

  • Making sure I know how good I have to be at the game to be ahead of all the Mid-Offs Players
  • Seeing wether or not better Mid-Offs performance correlates with better Ranked performance

All the data for this website is compiled from the MCSR Ranked Api and RQL.
